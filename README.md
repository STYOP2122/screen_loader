# Screen Loader

ASI-плагин для GTA San Andreas, который заменяет стандартный экран загрузки собственным изображением и добавляет плавную полосу прогресса внизу экрана.

## Возможности

- Изображение загрузки на всю область экрана.
- Полоса прогресса на всю ширину экрана, без текста.
- Отрисовка через Direct3D 9.

## Сборка

Понадобятся Windows, Visual Studio с инструментами C++ v143 и Windows SDK, а также DirectX SDK (June 2010) с заголовками `d3dx9.h` и `d3dx9core.h`. Пути к DirectX SDK задаются через `DXSDK_DIR` либо соответствующие настройки проекта.

1. Откройте `screen_loader.sln` в Visual Studio.
2. Выберите конфигурацию **Release / Win32**.
3. Соберите решение.

Результат: `bin/Release/screen_loader.asi`.

## Установка

1. Установите ASI Loader для GTA San Andreas.
2. Скопируйте `screen_loader.asi` в папку игры рядом с `gta_sa.exe`.
3. Поместите туда же изображение с именем `screen_loader.png`.

Плагин загружает именно `screen_loader.png`. Текущий шаг копирования в проекте сборки использует другое имя — `customloadscreen.png`, поэтому требуемое изображение нужно скопировать вручную.

## Структура

- `source/screen_loader.cpp` и `.h` — экран загрузки и полоса прогресса.
- `source/loader.cpp` и `.h` — точка входа и хуки.
- `d3d9/` — отрисовка и текстуры.
- `llmo/` — хуки вызовов.
- `CGame/` — типы и заголовки игры.
